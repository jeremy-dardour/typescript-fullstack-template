# Architecture decisions

Accepted ADRs are immutable historical records, including their status text.
To reverse or change a decision, add the next numbered ADR; link to the previous
one and state exactly which decisions it supersedes, why, and the consequences.
Preserve unaffected decisions. Read later superseding ADRs before treating an
older decision as current. Draft ADRs may be revised before acceptance.

Keep current implementation guidance in standards and link to the deciding ADR.
Use a short context, decision, rationale, and consequences; do not turn an ADR
into a running implementation log.
